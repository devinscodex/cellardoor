CELLARDOOR  -  CLI / TUI MOCKUPS
Plain 7-bit ASCII, 72 columns max, no color required, no dependencies.
All names, addresses and ids below are made up (example.com).

Door states used everywhere:
  [ ] open    signed in
  [/] ajar    invited, not yet used
  [#] closed  disabled or locked

4b. INVITE A GUEST
----------------------------------------------------------------------

   cellardoor invite carol@example.org --role guest --days 30

   Invite created
     person    carol@example.org
     role      guest
     expires   2026-11-22
     link      https://auth.example.com/invite/Zk3mQ9...   (shown once)

   The link works once. Only its hash is stored.
   Send it yourself; cellardoor does not send mail.

6. ERRORS (short, say what to do, never print secrets)
======================================================================

   cellardoor: sign-in refused
     the token came from a tenant that is not on the allowlist.
     fix: add the tenant in config.toml under [entra] allowed_tenants,
          or ask the user to sign in with the right account.

   cellardoor: config not loaded
     /etc/cellardoor/config.toml is readable by other users (mode 644).
     fix: chmod 600 /etc/cellardoor/config.toml

======================================================================
7. HELP
======================================================================

   cellardoor <command> [options]

   install      create config, database and pepper
   config       change settings
   user         list, add, disable, enable, role, reset, delete
   invite       create a one-time invite link
   audit        show the audit log
   check        run self-tests and report problems
   version      print version

   Environment: NO_COLOR is respected. Output is plain text.
