# Security policy

CellarDoor is pre-release. Report a suspected vulnerability privately through
GitHub security advisories on this repository ("Report a vulnerability" on the
Security tab). Do not open a public issue.

Include what you saw, how to reproduce it, and the version.

- Acknowledgement within 7 days.
- A fix or a plan within 30 days for a confirmed issue.
- Details are published after the fix is released.

In scope: the code in this repository. Out of scope: your reverse proxy, your
host, and denial of service by raw traffic volume.

Testing against your own installation is welcome. Do not test against a
deployment you do not own.

The design is public on purpose. A report that only says "the source is readable"
is not a vulnerability.
